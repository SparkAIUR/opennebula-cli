# Command Model

The preferred command grammar is:

```bash
one <resource> <verb> [args] [options]
```

Examples:

```bash
one vm list
one vm show 42
one image delete 13
one vnet list --output json
```

Compatibility shims remain available for the official OpenNebula-style workflow:

```bash
onevm list
onehost flush 3
oneimage show 13
onecluster list
```

## Subcommand help examples

Every implemented subcommand includes 1-2 examples directly in `--help`.

Example:

```text
$ one vm list --help
Examples:
  one vm list --output json
  onevm list --output json
```

## Output modes

- `table`
- `json`
- `yaml`
- `xml`
- `csv`
- `raw`
