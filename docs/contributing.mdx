# Contributing

## Development workflow

```bash
uv sync --group dev
uv run pytest
uv run ruff check .
uv run mypy src tests tools
uv build
```

## Contribution rules

- keep code typed and service-oriented
- avoid transport leakage outside `transports/`
- update public docs for user-visible changes
- update catalogs when the command surface changes
- do not commit `refs/*`
- keep live capture tooling read-only and add redaction tests for changes

## Private maintainer workspace

`refs/` is reserved for local-only working notes, internal task tracking, and the contextual knowledge store.

Tracked code may interact with the local context store via:

```bash
uv run python tools/context_store.py init
uv run python tools/context_store.py export-md
```

Read-only live capture workflow:

```bash
tools/capture_live_readonly.sh --write-artifact > /tmp/opennebula-capture.jsonl
uv run python tools/import_live_capture.py import --input /tmp/opennebula-capture.jsonl
```
