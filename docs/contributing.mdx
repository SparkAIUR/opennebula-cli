# Contributing

## Development workflow

```bash
uv sync --group dev
uv run ruff check .
uv run mypy src
uv run pytest
uv run python tools/check_catalog_schema.py
uv build
```

Optional `just` workflow:

```bash
just sync
just check
just build
just release-preflight v7.4.0
```

## Contribution rules

- keep code typed and service-oriented
- keep CLI handlers thin; reusable logic belongs in services
- avoid transport leakage outside `transports/`
- update public docs for user-visible changes
- update catalogs when the command surface changes
- do not commit `refs/*`
- keep live capture tooling read-only
- add or update redaction tests when capture behavior changes
- keep disposable E2E fixtures namespaced under `e2e-*`

## Release process for `7.4.x`

Public package versions now mirror the targeted OpenNebula compatibility line.

Rules:

- release tags must equal `project.version`
- GitHub Actions publishes to PyPI only when the pushed tag matches the package version exactly
- `7.4.0` targets OpenNebula 7.4 and retains the complete 7.0 profile
- `0.1.0` remains only as the historical bootstrap release

Preflight a release tag locally with:

```bash
uv run python tools/check_release_version.py --tag v7.4.0
```

## Required release gates

Before tagging a compatibility release:

- local lint, typing, tests, and build must pass
- catalog validation must pass
- authenticated target-line read-only evidence and both transport backends must pass
- mutation evidence must remain separate; never use production or non-`e2e-*` resources
- public docs must match the real CLI contract and version markers

## Private maintainer workspace

`refs/` is reserved for local-only notes, task tracking, live capture artifacts, and the contextual knowledge store.

Tracked code may interact with the local context store via:

```bash
uv run python tools/context_store.py init
uv run python tools/context_store.py export-md
```

Read-only live capture workflow:

```bash
tools/capture_live_readonly.sh --write-artifact > /tmp/opennebula-capture.jsonl
uv run python tools/import_live_capture.py import --input /tmp/opennebula-capture.jsonl
```
