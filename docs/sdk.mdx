# SDK

The public SDK entrypoint is:

```python
from opennebula_cli.sdk import OneClient
```

## Constructors

```python
OneClient.from_env()
OneClient.from_profile("prod")
OneClient.from_config(config)
```

## Current services

- `client.vm`
- `client.host`
- `client.image`
- `client.template`
- `client.vnet`
- `client.datastore`
- `client.cluster`

## Example

```python
from opennebula_cli.sdk import OneClient

client = OneClient.from_env()

for network in client.vnet.list():
    print(network.id, network.name, network.type)
```

## Current public exceptions

- `OpenNebulaError`
- `AuthError`
- `ConnectionError`
- `TlsError`
- `TimeoutError`
- `ApiError`
- `PluginError`

## Rule for contributors

If a CLI feature requires new logic, implement it through the service layer so the SDK can reuse it.
