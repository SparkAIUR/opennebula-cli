# Getting Started

## Requirements

- Python `3.11+`
- `uv`
- network access to an OpenNebula `7.0.x` endpoint
- credentials available through an auth file, profile, or explicit CLI/env auth

## Install

Install the released CLI:

```bash
uv tool install opennebula-cli==7.0.0
```

Or run directly without a persistent install:

```bash
uvx --from opennebula-cli==7.0.0 one --help
```

For repo development:

```bash
uv sync --group dev
uv run one --help
uv run onevm --help
uv run onevnet --help
```

## Recommended auth setup

Use an auth file instead of a raw secret in shell history:

```bash
mkdir -p "$HOME/.one"
chmod 700 "$HOME/.one"
printf 'oneadmin:super-secret-token\n' > "$HOME/.one/one_auth"
chmod 600 "$HOME/.one/one_auth"
```

Then point the CLI at your endpoint:

```bash
export ONE_XMLRPC="https://opennebula.example.com/RPC2"
export ONE_AUTH="$HOME/.one/one_auth"
```

## First commands

Canonical commands:

```bash
one vm list
one host show 0
one --output json image list
one --output yaml cluster show 0
```

Compatibility shims:

```bash
onevm list
onehost show 0
oneimage --output json list
onecluster --output yaml show 0
```

## Important command syntax rule

Global options must appear before the resource verb:

```bash
one --output json vm list
onevm --output json list
```

These are not valid:

```bash
one vm list --output json
onevm list --output json
```

## SDK quickstart

```python
from opennebula_cli.sdk import OneClient

client = OneClient.from_env()
vm = client.vm.show(42)
print(vm.name, vm.state)
```

## Safe live observation

When credentials cannot be shared, generate a sanitized read-only capture:

```bash
tools/capture_live_readonly.sh --write-artifact > /tmp/opennebula-capture.jsonl
uv run python tools/import_live_capture.py import --input /tmp/opennebula-capture.jsonl
```

The capture tool only runs allowlisted `--help`, `list`, and `show` commands and redacts sensitive infrastructure details before you share the output.
