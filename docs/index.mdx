# opennebula-cli

`opennebula-cli` is a modern Python CLI and SDK for OpenNebula `7.0.x`.

It provides:

- canonical commands such as `one vm list`
- compatibility shims such as `onevm list`
- a typed SDK under `opennebula_cli.sdk`
- deterministic machine-readable output modes
- a plugin-ready architecture for future OneFlow and ecosystem integrations

## Design stance

- Compatibility comes first.
- Modernization must stay additive.
- The SDK is first-class, not a subprocess wrapper.
- Human output can improve, but machine output must stay stable.

## Current milestone

The current tracked milestone is `Foundation + Wave 1`:

- packaging, CI, and developer workflow
- config/auth/runtime state
- PyONE-backed transport and raw XML-RPC fallback
- renderers and waiters
- `vm`, `host`, `image`, and `template` command families
