# Testing

The repo uses layered validation:

- unit tests for isolated logic
- snapshot tests for CLI and output drift
- golden tests for imported private live summaries when available
- contract tests against private read-only capture artifacts when available

## Local checks

```bash
uv run ruff check .
uv run mypy src tests tools
uv run pytest
uv run python tools/check_catalog_schema.py
```

## Live capture workflow

```bash
tools/capture_live_readonly.sh --write-artifact > /tmp/opennebula-capture.jsonl
uv run python tools/import_live_capture.py import --input /tmp/opennebula-capture.jsonl
```

The `contract` and `golden` suites skip cleanly when private artifacts are not present under `refs/tasks/live-capture/`.
