# Parity Roadmap

The command parity program is tracked in YAML catalogs under `src/opennebula_cli/catalogs/v7_0/base/`.

## OpenNebula 7.0.2 captured coverage

Implemented for the captured 7.0.2 command families in `refs/notes/full-commands-7.0.2.md`:

- `onevm`
- `onehost`
- `oneimage`
- `onetemplate`
- `onevnet`
- `onedatastore`
- `onecluster`
- `oneflow-template`

The first full-coverage pass provides command availability, required arguments, and core/high-value options through the service layer. Commands that already have typed SDK paths keep those typed implementations. The broader official parity surface uses a generic XML-RPC-shaped runner so each captured verb is available in canonical form and through the compatibility wrappers.

Validation status:

- local command coverage check passes for all captured commands
- unit/static tests use fake transports only
- no live credential or remote OpenNebula validation is part of this pass

## Remaining roadmap

Future parity expansion should target additional OpenNebula command families not present in the 7.0.2 capture used for this pass:

- `oneuser`, `onegroup`, `oneacl`, `onezone`, `onevdc`
- `onesecgroup`, `onevmgroup`, `onemarket`, `onemarketapp`
- OneFlow/plugin-backed commands

## Release policy

Public package versions mirror the targeted OpenNebula compatibility line.

- current release: `7.0.2`
- compatibility target: OpenNebula `7.0.x`
