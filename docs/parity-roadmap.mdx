# Parity Roadmap

The command parity program is organized in waves.

## Wave 1

- `onevm`
- `onehost`
- `oneimage`
- `onetemplate`

## Wave 2

- `onevnet`
- `onedatastore`
- `onecluster`

## Wave 3

- `oneuser`
- `onegroup`
- `oneacl`
- `onezone`
- `onevdc`

## Wave 4

- `onesecgroup`
- `onevmgroup`
- `onemarket`
- `onemarketapp`

## Plugin wave

- OneFlow plugin boundary
- plugin diagnostics
- entry-point based registration

## Tracking

Each family is represented in YAML catalogs under `src/opennebula_cli/catalogs/v7_0/base/`.
