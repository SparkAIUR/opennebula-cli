# Parity Roadmap

The command parity program is organized in waves.

## Wave 1

- `onevm`
- `onehost`
- `oneimage`
- `onetemplate`

Current status:

- `list`, `show`, and the currently exposed mutating commands are implemented
- read-only live verification is available for `list` and `show`

## Wave 2

- `onevnet`
- `onedatastore`
- `onecluster`

Current status:

- `list` and `show` are implemented
- mutating Wave 2 verbs remain cataloged, not implemented

## Wave 3

- `oneuser`
- `onegroup`
- `oneacl`
- `onezone`
- `onevdc`

## Wave 4

- `onesecgroup`
- `onevmgroup`
- `onemarket`
- `onemarketapp`

## Plugin wave

- OneFlow plugin boundary
- plugin diagnostics
- entry-point based registration

## Tracking

Each family is represented in YAML catalogs under `src/opennebula_cli/catalogs/v7_0/base/`.
